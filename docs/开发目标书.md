## 一、一句话定义（所有人背下来，不许改）

**把一堆群通知粘进来，30 秒变成一条不会错过的截止日清单，能一键导进手机日历。**

四句话版本（答辩开场，必须练到 30 秒内说完）：

- **给谁用**：每个学期都要盯十几个群的大学生，尤其班委和社团干事。
- **解决什么**：通知埋在几百条聊天记录里，截止日靠人记，漏一次就是一次挂科风险。
- **第一步点什么**：把群消息整段粘进来，点"解析"。
- **最后看到什么**：一份按紧急程度分好组的清单（3 天内标红），点一下导进手机日历。

**对外的一句话（路演开场第一句，写死）**：

> 群里的截止日，直接进你手机日历，断网也能用。

> ⚠️ 不要讲成"AI 帮你总结群消息"。腾讯元宝已经内置了群聊总结，这么讲等于自证重复。你们的位置是**最后一公里**。

## 二、为什么是这个题（被问"为什么做这个"时照说）

1. **痛点人人有**，评委自己也在群里被通知淹过，不需要铺垫背景。
2. **链路极短**：一个输入框、一个按钮、一屏结果。24 小时内做得完，做得完才有完成度分。
3. **断网可演示**：文字规则在本地跑，拔网线仍能出结果。这是对"现场网络挂了"最硬的兜底。
4. **导进日历这一步，把"AI 帮你总结"和"AI 帮你干活"分开了**。总结完还得你自己记；导进日历，两个月后手机会提醒你。

## 四、实现方式：一条主链路，四个契约

数据只能单向流动，任何一段都不许跨层：

```
#input 里的文字
   → extract(text) → items[]     ← 纯函数，不碰 DOM，可单独测
   → render(items)               ← 只负责画，不改数据
   → doIcs(items)                ← 生成文件下载
```

### 契约 1 · 数据结构（11.07 12:00 冻结，之后一个字都不许改）

```json
{
  "items": [
    {
      "title": "交创新学分汇总表",
      "due": "2026-11-13",
      "time": "18:00",
      "materials": ["汇总表"],
      "source": "请各班于本周五 18:00 前把汇总表发到学工办邮箱",
      "urgent": false
    }
  ]
}
```

- `due` 一律 `YYYY-MM-DD`，没有日期就 `null`
- `time` 没有就 `null`，有就 `HH:MM`（24 小时制）
- `materials` 是数组，没有就空数组
- `source` 保留原句，答辩时用来证明"不是瞎编的"

### 契约 2 · DOM 五件套（谁改 id，谁负责修好白屏）

`#input` `#run` `#sample` `#clear` `#result`

### 契约 3 · 函数边界

- `extract` 只管产出数组，**不碰任何 DOM**
- `render` 只管画数组，**不改数据、不做解析**
- 两个人各自改自己的文件，不需要读懂对方的代码

### 契约 4 · 胶水唯一

`run()` 只写在 `app.js`，是唯一把输入、解析、渲染串起来的地方。

### 文件怎么分（11.07 10:30 花 20 分钟，超时就退回单文件）

| 文件 | 谁 | 内容 |
|---|---|---|
| `index.html` | lfl 主管，**改前报备** | 结构 + 引用，冻结后不动 |
| `style.css` | lfl 独占 | 样式 |
| `ui.js` | lfl 独占 | `render` / `renderState` |
| `app.js` | 你独占 | `parseWhen` / `extract` / `doIcs` / `run` |

**三条技术红线**：

1. **不用 `type="module"`** —— `file://` 下会被浏览器直接拦掉，页面一片白
2. **不用任何 CDN** —— 断网就废，而断网演示是你们的核心卖点
3. **主流程不依赖网络请求** —— 网络只服务 F4 这一个加分项

**拆不成功的退路**：退回单文件，按时间段独占（12:00–15:00 lfl 改样式，15:00–18:00 你改逻辑），中间只说话不动手。

## 五、AI 怎么接：做成"可选增强"，不做成"必需品"

这是本次唯一的技术路线决策，方案如下：

- 页面留一个折叠区「高级：填入 API Key」，**留空就用纯规则跑**
- 填了 key：先跑规则，再让模型按**同一份 JSON 结构**返回，合并结果
- **失败 / 超时 / CORS 被拦 → 静默回落**，界面不报错，只在角落显示"本地模式"
- 答辩时这是加分项：**现场拔网线演示**，然后说"AI 是增强层，不是命脉"

**11.07 上午必须做的 20 分钟验证**：新建一个空白 `test.html`，在控制台直接调一次模型接口。

- 返回 JSON → 按上面接
- 报 CORS 红字 → **不要临时写代理**（两小时起，未必成）。只保留规则层，AI 用录屏演示，答辩里如实说"浏览器跨域限制，正式版会放到服务端"

> 能把这句话讲清楚，比硬接上去更得分。

## 九、答辩高频四问（标准答法）

**Q1：这不就是把 ChatGPT 套了个壳？**
> "让 ChatGPT 整理，你得到一段文字，还得自己记。我们的结果能导出成日历事件，进你手机，两个月后手机会响。而且我们做了规则引擎，断网也能用——套壳产品断网就废。"

**Q2：腾讯元宝不是能总结群聊吗？**
> "能，但它出的是纪要，你还得自己记下、自己设提醒，而且必须联网。我们更窄也更明确：粘贴、出清单、导进手机日历，断网也能跑。我们不做平台，只做最后一公里。"

**Q3：AI 抽错了怎么办？**
> "每一条都保留来源原句，用户一眼能看出是从哪句话抽的，界面上可以直接改。我们不假装 100% 准确，我们保证错了你能立刻发现。"

**Q4：这东西别人一个下午就做出来了。**
> "做出来不难，难的是让它值得信任。我们花时间做的是日期歧义处理（'下周三''月底前''本周五 18 点'）和断网降级。这两件事决定它是玩具，还是能天天用的工具。"
