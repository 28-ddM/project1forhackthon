# 竞品地图与答辩话术（截至 2026 年 11 月）

> 用途：明天评委问"这和 XX 有什么区别"时，照着答。  
> 结论：两个方案都有竞品，但**竞品密度完全不同**——A 是填空，C 是硬碰。

---

## 一、A 方案的竞品（群消息 → 待办 → 日历）

| 产品                                            | 做到哪一步                                   | 差在哪                                    |
| --------------------------------------------- | --------------------------------------- | -------------------------------------- |
| **腾讯元宝**（微信 / QQ）                             | 群聊记录 → 纪要 + 待办事项，QQ 群内有内置入口             | 出的是"纪要"，不是能落地的清单；微信端要手动转发；必须联网；不导出日历   |
| **Coze「群待办不漏事」**（技能）                          | 粘贴群聊 → 待办 + 责任人 + 截止时间 + 原文溯源，零 API Key | 纯提示词，无导出能力，无日历，无界面，得在 Coze 里用          |
| **Aemeath Bot**（GitHub 开源）                    | 读 QQ 白名单群 → 待办 → 自动写进 iPhone 提醒事项和日历    | 要一台 24 小时开机的电脑 + NapCat + MCP，普通学生部署不了 |
| **Motion / Reclaim / Todoist AI / Notion AI** | 从邮件、Slack、文档抽任务并自动排期                    | 全英文为主；面向职场；要订阅；不碰中国大学生的群通知             |
| **Gemini in Gmail**                           | 邮件一键转任务                                 | 只在 Gmail 生态内                           |

**空白位置在哪**：没有任何一个做到"**双击就能用 + 离线 + 结果直接进你手机日历**"。大厂不做，因为它们要你留在它的生态里；开源方案不做，因为极客不在乎易用性。

## 二、C 方案的竞品（录音 / PDF → 笔记 + 导图 + 题卡）

| 产品                                                      | 规模 / 状态               | 能力                          |
| ------------------------------------------------------- | --------------------- | --------------------------- |
| **NotebookLM**（Google）                                  | 免费额度大，学生广泛使用          | 来源引用 + 摘要 + 测验 + 音频概览       |
| **StudyFetch**                                          | 自称 800 万用户            | 录音 / PDF → 笔记、闪卡、测验、AI 导师   |
| **Turbo AI（原 TurboLearn）**                              | 2026 年 7 月宣称 1000 万用户 | 录音 / PDF / 视频 → 笔记、闪卡、播客    |
| **Mindgrasp / Coconote / Studr / Memo AI / Studyflash** | 各自数万至百万级              | 与上面高度同构，差异只在闪卡算法、导出格式       |
| **通义听悟**（阿里）                                            | 国内主流，API 约 0.6 元/小时   | 转写 + 摘要 + 章节 + 思维导图 + 翻译    |
| **讯飞听见**                                                | 老牌                    | 逐字稿准确率高，提炼偏弱                |
| **飞书妙记**                                                | 飞书生态内                 | 实时转写 + 纪要 + 待办              |
| **话袋 AI**                                               | 国内课堂场景                | 边录边出字 + 去口语 + 卡片化 + 按课程标签归档 |

**结论**：C 是红海中的红海。全球至少十几个成熟产品，其中两家自称千万级用户，而且"录音 → 笔记 → 导图 → 题卡"这个组合是它们的**标配**，不是差异化。

## 三、为什么这两个"都有竞品"的性质不一样

- **A 的竞品是"顺带做的功能"和"极客玩具"**，中间留了一条清晰的缝：零安装、离线、最后一公里落到日历。你可以站在这条缝里。
- **C 的竞品是"专门做这件事的公司"**，已经做到千万用户、有移动端、有闪卡算法、有学术背书。你要在同一个位置正面打，而你的版本功能更少、更慢、更不稳。

**黑客松里，评委不会因为"有竞品"扣分，但会因为"你没有区别"扣分。**

## 四、答辩话术（背下来）

### 如果被问"腾讯元宝不是能总结群聊吗？"

> "能，但它出的是纪要，你还得自己记下来、自己设提醒。而且它必须在微信里转发出去、必须联网。我们做的更窄也更狠：粘贴、出清单、导进你手机日历，断网也能跑，双击就能开。我们不做平台，只做最后一公里。"

### 如果被问"开源不是有现成的吗？"

> "有，那个方案要一台常开的电脑、装 NapCat 读 QQ、再接 MCP。我们能装，我室友装不了。学生要的不是能搭起来，是双击就能用。"

### 如果被问"这不就是通义听悟 / NotebookLM？"（只有做 C 才会遇到）

> "它们做的是通用笔记。我们只做考前 72 小时的复习包：不生成摘要，只抽考点和自测题，而且每道题必须能点回原句。这是我们和它们的唯一区别，也是我们故意收窄的地方。"

---

## 五、一句话记住

**A 的竞品在你们要去的地方旁边；C 的竞品就站在你们要去的地方上面。**
