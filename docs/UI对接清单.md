# UI 视觉规范与改造边界

> 这份文档是界面的「施工图」：写清楚视觉规范、哪些能改、哪些碰了功能就坏、改完怎么自测。
> **2026-11-07 傍晚更新**：暖黄主题已按规范落地到 `index.html`，本文档同步为当前实现。

---

## 一、当前视觉规范（已实现，改动前先读）

| 项目 | 规则 |
|---|---|
| 基调 | 低饱和柔和暖黄，奶白卡片 + 暖米色页面底；其余一律中性灰，禁止荧光色、彩虹色 |
| 圆角 | **只有两个值**：卡片 / 事项 / 空状态 / 确认框用 `--radius: 16px`，小控件用 `--radius-sm: 10px`。唯一的例外是缩略图关闭按钮的圆形（`50%`） |
| 阴影 | **全站只用 `--shadow-sm`**（`0 1px 2px rgba(58,51,44,.07)`）。禁止重阴影、多层阴影、发光 |
| 字体 | 系统无衬线字体；标题 600，正文 400，辅助小字 350，不用粗黑字体 |
| 栅格 | 8px 基准，间距取 8 / 16 / 24 |
| 交互 | 卡片 hover **只轻微加深边框颜色**，不放大、不上浮、不弹跳；按钮 hover **只变暗**，无发光、波纹、渐变；所有过渡 `200ms ease` |
| 插图 | 只在「整份清单为空」时出现一只托腮引导插图，其余空状态只有文字。不铺满页面、不用 emoji |
| 明确禁止 | 玻璃拟态、大面积渐变背景、漂浮粒子、花哨动效、弹窗抖动、网红卡通风、随机圆角与多种阴影 |

**关于 Tailwind CSS**：规范里提到 Tailwind，但项目**没有引入**。原因不是偷懒——Tailwind 走 CDN，断网时样式全部丢失，而这个产品的核心卖点恰恰是「断网也能用」。规范要求的全部效果用原生 CSS 变量就能实现，且保持零依赖、双击就跑。视觉照搬，技术栈不动。

**关于三屏结构**：模式选择页 / 工作台 / 日程周历**已经做成一个 `index.html` 里的三个 `<section>`**（`#screen-mode` / `#screen-app` / `#screen-cal`），用 `hidden` 属性切换，顶部 `#topnav` 导航在模式屏隐藏。所有元素仍在同一份文档里，脚本 `getElementById` 全部有效。**不要把任何一屏拆成第二个 HTML 文件**——脚本开头是一批 `getElementById`，元素不在那一页就是 `null`，整页按钮失效。

## 二、四条红线：这些动了就白干

### 1. 不要动 `<script>` 里的任何一行

`<style>` 结束之后那一大段是逻辑代码：解析日期、存清单、调 AI、导出日历。改样式完全不需要碰它。

### 2. 不要删、不要改名任何 `id`

JS 全靠这些 id 找元素，删一个就是一片功能失效。当前一共 **56 个**：

```
三屏骨架   screen-mode  screen-app  screen-cal  topnav
顶部导航   navMode  navHome  navCal  navGuest
模式屏     modeGrid  modeGo  connectBox  connGrid
           customUrlRow  customUrl  modeKey  modeRemember
           verifyBtn  verifyStatus  fallbackBox  fallbackMsg
           fallbackLocal  fallbackRetry
输入区     input  run  clip  clear  sample  pick  file  thumbs  inputCard
清单区     stats  result  tabs  ops  ics  copy  wipe  localNote
AI 面板    aibox  aiSum  aiKey  aiTest  aiRemember  aiStatus
日历屏     weekBar  weekTitle  weekPrev  weekNext  calFilter  calList
提示确认   toastWrap  mask  dlgText  dlgYes  dlgNo
```

`clip` 是「读取剪贴板」按钮，`toastWrap` / `mask` 那一组是自定义提示与确认框。

### 3. 这些 class 是 JS 动态生成的，改名要同步改 JS

元素不在 HTML 里，是运行后由脚本创建的。CSS 里改了名字，脚本创建的还是旧名字，样式就套不上：

```
.item          每条待办卡片（工作台和日历共用）
.thumb         截图缩略图
.tag           材料小标签
.group-title   分组标题（3天内 / 周历里的日期）
.empty         空状态提示块
.empty-msg     空状态里的文字
.mascot        空状态里的引导插图（工作台、日历各一张）
.ai-sum        折叠标题上的「已就绪」小字
.toast         轻提示条
.dialog        确认框
.day-cell      周历格（叠 .today 今天 / .pick 选中 / .dim 过去）
.dots i        周历格下的截止日圆点
```

`.mode-card` / `.conn-card` 在 HTML 里，但它们的 `.on` 选中态由脚本切换，别改 `.on` 的名字；`.mode-check` 是卡片右下角那个对勾，只靠 `.on` 里的 `opacity` 显示。`.local-note` 只在本地模式下显示，靠 `hidden` 属性控制，别改成 `display:none` 内联样式。`.item` 还会叠 `g-urgent` / `g-soon` / `g-far` / `g-over` / `g-nodate` 表示紧急程度。**左边框颜色专门留给紧急程度**，hover 只能动另外三条边。

### 4. 不要拆掉 `<details>` / `<summary>` 的折叠结构

「AI 概括」靠 `<details>` 展开收起。现在截图识别不再自动展开它：没接入 AI 时点截图会提示去模式页，切回本地模式时脚本会 `$aiBox.open = false` 收起它。别把它改成常驻展开的 div。

### 5. 不要再写 `alert()` / `confirm()`

浏览器原生框在手机上是系统级深色弹窗，跟页面两张皮。全部换成了页面内组件。以后加功能要弹提示，用 `toast("文字")`；要确认，用 `ask("文字", 回调)`。

## 三、换配色：只改 `:root`

`<style>` 开头那段 `:root { ... }` 是全站配色，改值整页跟着变，碰不到逻辑。当前值：

```css
:root {
  --accent: #f0b429;       /* 品牌主色：奶黄 */
  --accent-deep: #d99a1c;  /* 主色加深 / slogan */
  --accent-soft: #fdeccb;  /* 主色浅底 */

  --ink: #3a332c;          /* 主文字：暖深棕 */
  --ink-deep: #2a241e;     /* 主按钮 hover */
  --on-ink: #fffdf8;       /* 压在深色上的文字 */
  --ink-2: #574f44;        /* 次一级文字 */
  --muted: #8a8175;        /* 说明文字 */
  --muted-2: #a39a8c;      /* 分组标题 */
  --muted-3: #6b6257;      /* 标签文字、折叠标题 */
  --src: #8f8577;          /* 原文出处 */
  --faint: #b3aa9c;        /* 辅助 / 占位 */

  --line: #efe6d4;         /* 卡片描边、分隔线 */
  --line-2: #e2d7c0;       /* 输入框与按钮描边 */
  --line-3: #e8dcc6;       /* 事项左边框、缩略图、空状态虚线 */

  --bg: #faf5ea;           /* 页面底：暖米白 */
  --surface: #fffdf8;      /* 卡片底：奶白 */
  --surface-2: #f6f0e1;    /* 浅底块（原文出处、提示条） */
  --surface-3: #faf5ea;    /* 已完成项 */
  --tag-bg: #f3ead6;       /* 材料标签 */

  --danger: #d97a6c;       /* 紧急、删除、错误（低饱和） */
  --danger-line: #ecc9c2;
  --warn: #d9a13b;         /* 一周内 */
  --ok: #6ba883;           /* AI 就绪、成功 */
  --ok-line: #c9e0d2;
  --ok-bg: #f2f7f0;
  --link: #d97706;

  --radius: 16px;          /* 统一圆角 */
  --radius-sm: 10px;       /* 小控件 */
  --shadow-sm: 0 1px 2px rgba(58, 51, 44, .07);  /* 全站唯一阴影 */
}
```

⚠️ 三个注意：
- **别在变量定义里写 `var()`**（比如 `--ink: var(--ink)`），会循环引用，整站变黑
- `--on-ink` 是「压在深色底上的文字」，做深色主题时要继续保持高反差
- 改 `--radius` / `--radius-sm` 就够，别在下面零散写 `border-radius: 6px` 之类的数值

## 四、可以放开改的部分

| 能改 | 说明 |
|---|---|
| 字号、行高、字距 | 移动端基准 16px 起，别小于 13px |
| 间距、内距 | 走 8px 栅格，改两个圆角变量即可 |
| 布局 | 单列流式，改成卡片网格也行，但**手机上不能出现横向滚动** |
| 按钮样式 | 主按钮 `button.primary`，危险按钮 `.ops .danger` |
| 字体 | `body` 的 `font:` 那一行 |
| 桌面端 | 已有 `@media (min-width: 900px)`，可继续加宽屏规则 |

**加新元素可以，但要遵守第 2、3 条**：新加的交互控件要么只做纯展示，要么先和写逻辑的人说一声，让他给你绑事件。

### 提示与确认：两个可以随便美化的组件

| 组件 | class | 用在哪 | 相关变量 |
|---|---|---|---|
| 轻提示 | `.toast-wrap` / `.toast` | 「加入 3 条，1 条已存在被跳过」 | `--ink`、`--on-ink`、`--radius-sm` |
| 确认框 | `.mask` / `.dialog` | 只有「清空全部清单」会弹 | `--surface`、`--ink`、`--radius` |

几条不能删的属性：

- `.toast` 的 `white-space: pre-line` —— 多行提示靠它换行
- `.toast-wrap` 的 `pointer-events: none` —— 删了会挡住底部按钮
- `.mask[hidden] { display: none; }` —— 确认框靠 `hidden` 属性隐藏
- 别改 `.toast` 的 `box-shadow`，全站只允许 `--shadow-sm`

### 空状态插图

图片已抠成透明底，并以 `data:image/png;base64,...` 内联在 JS 的 `MASCOT` 常量里。这样单文件分发、`file://` 打开、断网都能显示，不依赖 `assets/` 目录。要换图就替换这个常量；原始素材在 `assets/`。

## 五、现在还剩下的短板（按性价比排序）

1. **危险按钮仍不够区分**：「清空全部清单」和「复制成清单」长得接近，误点代价大。可以只给它换成 `--danger` 描边 + 浅红底，不动结构。
2. **规则模式的标题还是摘原句**：不填 Key 时标题会带省略号（如「各班班长于本周五 18:00 前将《创新学分汇总表》…」）。这是规则引擎的固有表现，README 里已如实说明；演示时记得填 Key。
3. **模式入口不够显眼**：导航右侧的「模式」按钮是回选择页的唯一入口，现在和「首页 / 日历」长得一样。可以给它加一个状态小圆点（本地=灰、AI=已接入绿），让评委一眼看出现在跑在哪套引擎上。

之前的三个短板（顶部信息薄、空状态太素、三屏结构）已解决。

## 六、改完必须自测这 10 件事

**用手机测，不是电脑。** 电脑上好看不代表手机上好看。

- [ ] 1. 首次打开是模式选择屏；本地卡默认选中（暖黄描边 + 对勾）；点「用本地模式开始」进工作台，导航显示「本地模式」
- [ ] 1b. 点「AI 模式」→ 接入区展开；不填 Key 点「验证接入」只提示先填 Key，不会进工作台；点「改用本地模式」能进工作台并显示分类说明
- [ ] 2. 工作台里标题、slogan、输入框、五个按钮显示正常，**没有横向滚动条**；清单为空时虚线框里有奶龙插图，**周围没有白色方块**
- [ ] 3. 点「填入示例」，直接出 12 条待办，并按「3 天内 / 一周内 / 更远 / 未注明日期」分组；连续点 8 次内不会重复同一套，右下角提示「示例 3/8 · 场景名」
- [ ] 4. 每条待办左侧竖条颜色不同（红 / 黄 / 绿 / 灰），hover 时左边框颜色**不变**
- [ ] 5. 点待办的勾选框，能打勾、文字变灰划线；点右侧 `×` 能删掉
- [ ] 6. 点「图片选取」能调起相册，选图后出现缩略图、能点 `×` 删；一次选超过 6 张会明确提示跳过了几张
- [ ] 7. 点「读取剪贴板」：https 下能读进输入框；本地 `file://` 不给权限时会提示改用 `Ctrl + V`，**不会假装成功**
- [ ] 8. 导航点「日历」进周历屏：七个日期格、今天高亮、有截止日的格子带彩色圆点；点某天只看那天，再点取消；关键词能过滤；手机上七格**不挤爆、不换行**
- [ ] 9. 加入几条后点「清空全部清单」，弹出的是**页面中间的白色确认框**，不是系统黑框；点「取消」不会清空
- [ ] 10. 点「下载日历文件 .ics」能下载（微信里打开会失败，用系统浏览器测）

全过再交回。

## 七、怎么把成果交回来

**首选：直接改仓库里的 `index.html`。**

```bash
git pull
# 只改 index.html 的 <style> 段
git add index.html
git commit -m "[ui] 说明你改了什么，一句话"
git push
```

commit 写清楚改了什么，不要写 "update" 或 "改了一下"。

**如果 git 用不顺手**：把 `index.html` 直接发群里，说一句「我改了 style，没动 script」，由技术负责人合并。**千万别两个人同时改同一个文件再各自 push**，会冲突。

改崩了用保底版本回退：

```bash
git checkout v0.9-保底-手机已验证 -- index.html
```

## 八、一句话总结

> **你只管 `<style>` 里的事。`<script>` 一个字都别碰，56 个 id 一个都别删，动态 class 一个都别改名，16px 圆角和 `--shadow-sm` 别破坏。**

守住这句，怎么改都不会把功能改坏。
